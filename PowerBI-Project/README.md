# Nova Retail Group — Power BI Sales Dashboard

## Overview

An interactive Power BI dashboard developed for Nova Retail Group to analyse sales performance, profitability, customers, regions, channels and customer satisfaction.

This project uses the same dataset as the Nova Retail SQL project.

## Objective

Build an executive dashboard that allows management to quickly understand:

- Revenue performance
- Profitability
- Order performance
- Customer activity
- Regional performance
- Product category performance
- Online vs Store performance
- Customer satisfaction

## Data Model

The project uses a star-schema model consisting of:

- Sales
- Products
- Customers
- CustomerFeedback
- Date

The `Sales` table is the primary fact table.

## DAX Measures

Core measures include:

- Total Revenue
- Total Profit
- Total Orders
- Total Customers
- Average Order Value
- Profit Margin %

Analytical measures include:

- Previous Year Revenue
- YoY Growth %
- Customer Ranking
- Regional Ranking

## Dashboard

The dashboard contains:

- KPI cards
- Monthly revenue trend
- Revenue by category
- Revenue by region
- Online vs Store analysis
- Customer satisfaction
- Year slicer
- Region slicer
- Channel slicer

## Project Sections

### Part 1 — Data Modelling & Power Query

Data loading, data types, Date table, relationships and model organisation.

### Part 2 — Core DAX

Creation of the core business measures.

### Part 3 — Analytical DAX

Time intelligence, rankings and customer/category analysis.

### Part 4 — Dashboard

Development of the single-page executive dashboard.

### Part 5 — Insights & Storytelling

Development of data-driven insights and recommendations.

## Tools

- Power BI Desktop
- Power Query
- DAX
